# NT Studio

وكيل سطح مكتب شخصي يبني مشاريع حقيقية بالذكاء الاصطناعي — ينشئ المشروع محليًا، يشغّله،
يفحص النتيجة بصريًا ووظيفيًا، ثم يصلح ما يراه حتى يعمل.

## الأوامر

```bash
npm install        # تثبيت الاعتماديات
npm run dev        # تشغيل بيئة التطوير (Vite + Electron)
npm run build      # فحص الأنواع ثم بناء main/preload/renderer
npm run typecheck  # فحص الأنواع فقط
npm test           # اختبارات الوحدة
npm run dist       # بناء مثبّت ويندوز (.exe) في release/
```

## القرارات المعمارية المثبّتة

- **لا `type: module`** حتى تبقى `preload` بصيغة CommonJS ويظل `sandbox: true` فعّالًا.
- **لا اعتماديات native** (لا better-sqlite3 ولا Playwright): التخزين ملفات JSON ذرّية،
  والمعاينة عبر `WebContentsView` المدمج في Electron.
- **لا حزم ملوّنة بـ API SDK** الخاطئ: يُستخدم `@ai-sdk/*` المطابق للبروتوكول.
- **مسار التطبيق ASCII** (`D:\NT\Studio`) لتفادي مشاكل electron-builder/NSIS مع المسارات غير اللاتينية.
- **الأسرار مشفّرة** على القرص ولا تُمرَّر كاملة إلى الواجهة.
