# NT Studio

وكيل سطح مكتب شخصي يبني مشاريع حقيقية بالذكاء الاصطناعي — ينشئ المشروع محليًا، يشغّله،
يفحص النتيجة بصريًا ووظيفيًا، يصلح ما يراه، ثم يسلّم.

الاسم الداخلي `nt-studio` لأنه مشتق من بايتات التطبيق (ASCII) —see `docs/INSTALL.md`.

## التشغيل

```bash
npm install          # ثبّت Electron بمرآة (انظر docs/INSTALL.md)
npm run dev          # بيئة التطوير
npm run verify       # typecheck + فحص الترميز + 86 اختبارًا + build
npm run dist         # مثبّت .exe في release/
```

## البنية

```
src/
  main/              عملية Node: الوكيل، الملفات، الخوادم
    agent/           الحلقة والأدوات والاسترداد والذاكرة
    core/            المخزن، المسارات، السجل، الأسرار، السياق
    ipc/             معالجات محقّقة (ثقة المُرسِل + مخطط zod)
    preview/         WebContentsView للمعاينة
  preload/           جسر contextBridge — لا يُكشف ipcRenderer
  renderer/          React + Tailwind (بلا وصول لـ Node)
  shared/            الأنواع والعقود المشتركة
```

## قرارات لا تُكسر

| القرار | السبب |
| --- | --- |
| لا `"type": "module"` | يبقى `preload` CommonJS ⇒ `sandbox: true` فعّال |
| لا اعتماديات native | `better-sqlite3`/`Playwright` يحتاجان بناء منفصل-prone للفشل؛ استُبدلت بـ`WebContentsView` + مخزن JSON ذرّي |
| لا iframe للمعاينة | iframe يشارك مساحة JS مع الواجهة ⇒ كود المشروع يقدر ينادي الجسر ويحذف ملفاتك. `WebContentsView` عملية منفصلة |
| مسار ASCII للتطبيق | `electron-builder`/`NSIS` مشاكل موثّقة مع المسارات غير اللاتينية |
| fuses مفعّلة | `RunAsNode` و`NODE_OPTIONS` مُطفآن، وفحص سلامة asar مُفعّل |
| فحص الترميز في خط البناء | يمنع تلف UTF-8 من Editorial PowerShell — ثبتناه بعد وقوعها فعلًا |

## القيود المعروفة

- Windows فقط (تصميم الصدفة والأوامر).
- بلا توقيع كود (cert Authority) ⇒ SmartScreen سيحذّر على التثبيت.
- `npm audit`: 8 تحذيرات متوسطة من شجرة `electron-builder` (وقت البناء فقط، خارج حزمة التطبيق).
- لقطات الشاشة تُلتقط من العملية الرئيسية وتُمرَّر كـ base64 (حجم معقول، لا persist).
